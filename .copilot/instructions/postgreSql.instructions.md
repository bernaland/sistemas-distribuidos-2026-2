description: "PostgreSQL code style, conventions, architecture best practices for the project."
applyTo: "**/*.sql"
---

- Use PostgreSQL's latest version for database management.
- Use SQL for database queries and operations.
- Use proper indexing to improve query performance.
- Use transactions to ensure data consistency and integrity.
- Use views to simplify complex queries and improve maintainability.
- Use stored procedures to encapsulate business logic and improve code reusability.
- Use triggers to automate certain database operations and enforce business rules.
- Use constraints to enforce data integrity and prevent invalid data from being inserted into the database.

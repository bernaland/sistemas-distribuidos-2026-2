- Use Java and Spring Boot as the programming language and framework for backend services.
- Use dependency injection to register and utilize all necessary dependencies in the backend code.
- Use the package naming convention 'com.uelbosque.{service-name}' for all Java packages.
- Use design patterns where applicable to improve code maintainability and scalability.
- Follow the KISS (Keep It Simple, Stupid) principle to ensure code simplicity and clarity.
- Follow the SOLID principles to ensure code maintainability and scalability.
- Keep functions in any language used to a maximum of 20 lines.
- Use Java's exception handling mechanisms to handle errors and exceptions in the backend code.
- Use Java's logging framework to log important events and errors in the backend code.
- Use Java's unit testing frameworks, such as JUnit and Mockito, to implement unit tests for the backend code.
- After implementing a feature, ensure that all unit tests pass and that the code adheres to the established conventions and best practices.
- After implementing a feature, use code-review skills to ensure that the code adheres to the established conventions and best practices, and that it is maintainable and scalable.
- Use Java's security features, such as authentication and authorization, to secure backend services and protect sensitive data.
- Use Java's database access frameworks, such as JPA and Hibernate, to interact with the PostgreSQL database in the backend code.
- When common code is needed across multiple services, create a shared library to encapsulate the common code and promote code reuse.
- Use Java's configuration management features, such as application.properties and application.yml files, to manage configuration settings for backend services.
- Use Java's RESTful web service features, such as Spring MVC and Spring WebFlux, to implement RESTful APIs for backend services.

---
description: "Angular code style, conventions, architecture best practices for the project."
applyTo: "**/*.ts,**/*.js, **/*.html,**/*.scss"
---

- Use Angular's latest version for the front-end development.
- Use TypeScript as the programming language for the front-end.
- Use functional components instead of classes in the front-end.
- Name files in kebab-case for consistency.
- Follow the ATOMIC Design paradigm for designing user interfaces in the front-end.
- Use Bootstrap as the framework for creating content in the front-end.
- Use 'barrel' files in TypeScript to export components from a folder.
- Use const or let instead of var in TypeScript.
- Keep functions in any language used to a maximum of 20 lines.
- Use angular-developer skills to implement best practices and patterns in the front-end code.
- Use angular-testing skills to implement unit tests for the front-end code.
- After implementing a feature, ensure that all unit tests pass and that the code adheres to the established conventions and best practices.
- Use Angular's dependency injection to register and utilize all necessary dependencies in the front-end code.
- Use Angular's routing module to manage navigation between different pages and components in the front-end.
- Use Angular's forms module to handle user input and validation in the front-end.
- Use Angular's HTTP client module to communicate with backend services in the front-end.
- Use Angular's reactive programming features, such as Observables and RxJS, to handle asynchronous data streams in the front-end.
- After implementing a feature, use code-review skills to ensure that the code adheres to the established conventions and best practices, and that it is maintainable and scalable.

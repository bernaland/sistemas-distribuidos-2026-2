# Frontend (Angular) - Tienda Genérica

Estructura mínima creada para iniciar el desarrollo con Angular.

Pasos sugeridos:
- Instalar Angular CLI: npm install -g @angular/cli
- Instalar dependencias: npm install
- Ejecutar en dev: npm start

Notas:
- El proyecto creado es un esqueleto; usar `ng generate` para añadir componentes y servicios.
